# The spot — RL80 ad copy

This file is yours. The pipeline reads it; nothing else does.

Each `-` bullet below is one thing the show can plug in its commercial break.
The writer picks **one** per episode and builds the ad read around it: Kip
does the sponsor voice with full network gravity, and Holly reads the
disclaimer flatly, which is what ruins it. It is a joke about advertising. It
is never a recommendation to buy anything, and the pipeline's rules will not
let it become one.

**The writer never adds a claim the copy does not make.** A bullet written as a
finished read, in sentences meant to be said, is used word for word: Kip reads
the sponsor lines and Holly the disclaimer.

**If this file has no bullets, the segment is skipped** and the episode runs
without an ad break. That is a normal week, not a failure.

Keep each bullet to one or two sentences. Either write the *thing* and leave
the joke to the show, or write the finished read yourself. Delete a bullet once it has aired, or leave it and
it may be reused.
